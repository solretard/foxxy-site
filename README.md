# FOXXY

Landing site for the FOXXY NFT project — Ethereum.

## Files
- `index.html` — intro narrative with typewriter story and hero video
- `world.html` — four eras with animated videos, game coming-soon section
- `assets/` — all videos, posters, wordmark and fox art

## Local preview
```bash
cd foxxy-final
python3 -m http.server 8000
```
Then open `http://localhost:8000`

> Do NOT open index.html directly as a file — videos won't autoplay without a server.
